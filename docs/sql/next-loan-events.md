# QR ยืมและคืนครุภัณฑ์

ใช้ฐาน SQLite ที่แยกสำหรับ Next.js ตามเงื่อนไขใน `lib/sqlite/write-path.ts` สำรองไฟล์ฐาน Next.js ก่อนใช้ `next-loan-events.sql` กับไฟล์นั้นเท่านั้น เช่น

```sh
sqlite3 .daam-runtime/data/next-only.sqlite < docs/sql/next-loan-events.sql
```

เปลี่ยนชื่อไฟล์ตัวอย่างให้ตรงกับฐาน Next.js ที่ตั้งค่าไว้ การยืมและคืนจะตอบว่าให้เตรียมตารางก่อน หากฐานยังไม่มีตารางประวัตินี้ ระบบบันทึกแต่ละเหตุการณ์ควบคู่กับการเปลี่ยนสถานะในธุรกรรมเดียวกัน รายการเก่าคงข้อมูลเดิมและจะมีเหตุการณ์ใหม่เมื่อดำเนินการผ่าน Next.js

ทดสอบแบบแยกฐานด้วย `npm run test:qr-loan` ระบบสร้างและลบ SQLite ชั่วคราวเอง

บน iPhone เปิด DAAM Next.js ผ่าน HTTPS แล้วใช้เมนูสแกนในระบบ กล้องในเว็บอ่าน URL ของ QR เดิมเป็นรหัสครุภัณฑ์และนำไปที่ Next.js โดยตรง ส่วน QR เดิมที่ฝัง hostname หรือพอร์ต PHP จะยังเปิดปลายทางที่พิมพ์อยู่เมื่อเปิดผ่านแอปกล้องมือถือ ให้ใช้ตัวสแกนใน DAAM สำหรับสติกเกอร์เหล่านั้น หรือใช้สติกเกอร์ที่พิมพ์จาก Next.js สำหรับการเปิดโดยตรง
